    以下四个方向构成一条完整的技术叙事线：多视角编码 提供高效感知前端 → 4D 重建 提供时空底座 → 具身智能 在物理世界中感知与交互 → 世界模型 统一感知、预测与生成。你可以在任一方向深耕，也可以跨方向协作。

    📡 方向一：多视角图像 / 视频编码

    多视角采集（光场阵列、多摄相机组、分布式 VR/自由视点摄像）产生海量数据，但各视角间高度冗余——它们从不同角度观测同一物理场景，智能编解码器应能利用视角间几何相关性将压缩率提升数倍。

    经典方案是分布式信源编码，但现代学习型编解码器提供了更强大的选择：在网络内部直接对齐跨视角内容，使一个视角作为另一视角的辅助信息。核心挑战在于视差（parallax）——同一物体在不同视角中出现在不同位置与尺度，传统自注意力或光流对齐要么代价过高，要么本质上是视角非对称的。

    我们特别关注：

    • 视差感知注意力机制 — 高效对齐多视角内容，无需显式视差/深度估计
    • 分布式编码架构 — 主视角常规编码，侧视角基于跨视角条件编码，在严格分布式编码器下逼近联合编码性能
    • 编码与重建/世界模型的桥接 — 保留几何结构的多视角编解码器，是 4D 重建和世界模型的天然感知前端

    📄 代表作： ParaHydra (OmniParallax) — 首个显著超越 SOTA 多视角图像编解码器的分布式多视角图像压缩方法。核心创新 OmniParallax Attention (OPAM) 以立方计算复杂度显式建模任意信息源对之间的相关性与对齐特征；Parallax Multi-Information Fusion Module 自适应融合多源信息。中稿 CVPR 2026。

    🎞️ 方向二：4D 重建与生成

    4D 场景是随时间演化的三维场景——正是人类视觉系统实际感知的信号形式。我们的目标是：从有限输入（单目视频、稀疏多视角乃至含噪流式采集）中恢复照片级真实、时序连贯、可自由导航的动态场景表示，并在观测缺失时由生成先验合成动态世界。

    这一方向的技术挑战极高：动态场景打破了静态 3D 重建的几乎每一条假设——几何逐帧变化、时域观测极度稀疏、重建误差跨序列累积。实际部署还要求表示可流式构建、抗误差累积、实时渲染。

    我们特别关注：

    • 可流式 4D 表示 — 增量式构建与渲染，无需离线批处理
    • 抗误差累积的长序列重建 — 在数百甚至数千帧上从漂移、遮挡和缺失观测中恢复
    • 重建与生成的桥接 — 同一表示既可拟合真实采集，也可由生成先验想象——这是通往视频世界模型的天然跳板

    📄 代表作： SoLAR — 首个无需 GOP 分区即可维持长序列稳定重建质量的可流式自由视点视频框架。Anchor Activation Dynamics 更好地捕捉复杂非刚性变换；Latent Discrepancy Aware Recalibration 受比特分配理论启发，识别并校正潜在表征间的差异，有效抑制误差传播。投稿 TPAMI。

    🤖 方向三：具身智能

    具身智能 是指能够在物理或仿真环境中自主感知、理解、决策与行动的智能体——它不只”看见”世界，更要在世界中”做事”。与纯视觉理解不同，具身智能要求智能体将感知与行动闭环：观察环境 → 理解场景结构与物理规律 → 规划行动 → 执行并接收反馈 → 持续调整。

    我们团队在 4D 重建 和 多视角感知 方向的深厚积累，为进军具身智能提供了天然优势：4D 场景表示本身就是对物理世界的结构化理解，多视角编码则为智能体提供了高效的环境感知管道。我们正在探索如何将这些能力转化为具身智能体可用的空间认知与交互基础。

    我们特别关注：

    • 空间感知与场景理解 — 基于 4D 表示构建智能体对动态环境的结构化认知
    • 交互式场景重建 — 智能体在探索中主动采集信息，增量构建更完整的场景表示
    • 感知-动作闭环 — 从被动观测走向主动探索，让”重建”服务于”行动”

    🔭 具身智能是团队正在积极布局的前沿方向。我们已有坚实的技术储备，正寻找对这一方向充满好奇与热情的伙伴一起探索。

    🌍 方向四：世界模型

    世界模型 是物理与视觉世界的可学习内部模拟器：给定过去观测，预测场景未来将如何 看起来、运动 和 响应动作。世界模型是下一代视觉智能的核心——它在单一生成框架内统一感知、预测与决策，也是具身智能体”先想象、再行动”的基础。

    我们正在布局这一方向，重点探索：

    • 视觉真实感 — 直接从真实世界视频训练，捕获真实的场景物理、光照与运动
    • 长时一致 — 在数秒乃至数分钟的时间跨度上输出连贯、无漂移的预测
    • 几何感知 — 利用显式 3D/4D 表示（高斯、神经场），使想象出的未来在空间上合理
    • 可控 — 支持动作、相机与语义条件控制，使模型成为下游任务（规划、内容创作、具身 AI）的可用模拟器

    世界模型是我们四个方向的统一目标：4D 重建提供时空底座，具身智能提供感知-动作闭环，多视角编码提供高效感知管道，世界模型则将三者推向感知-预测-生成的闭环。具身智能体需要一个”内心模拟器”来规划行动，而世界模型正是这个模拟器——两者的结合将催生真正能在动态世界中自主行动的智能体。
